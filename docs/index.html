Spending the budget

Error correction is what pays for the maze. Every module the carving flips is damage the decoder has to repair, and each block of the symbol can absorb a fixed number of broken codewords before it is lost. Ask for more dead ends and more of that budget goes; ask for too many and the carver refuses the ones it cannot afford rather than breaking the code.

Drag the slider. The worst block reaches its limit by 60 attempts and everything after that is spent on blocks with room left, which is why refusals start appearing. Notice the dead ends peak at 41 and then fall to 21: opening more passages joins blind alleys into loops, so a bigger carving is not a harder maze.

The four levels

The same url at version 6, at each error correction level. A higher level corrects more and therefore carves more, and costs payload capacity to do it.

What the carving never touches

The finder patterns, the timing patterns, the alignment patterns and the format information are not data and are not covered by error correction. A single flipped module in any of them is not a damaged symbol, it is a symbol a scanner cannot find or cannot read the settings of. The carver treats them as walls that cannot be knocked through, and the measurement counts it.
